# was also served from a GitHub Pages staging host, where every page carried

#     <meta name="robots" content="noindex, nofollow">

# and a meta noindex outranks anything this file permits, which is why one
# file could be written for both. Staging is archived now and this is the only
# host; nothing in this file was ever the switch, and nothing here needs an
# edit for that.
#
# WHY THE ASSISTANTS ARE NAMED. Every agent below is already allowed by the
# wildcard -- absent a robots.txt entirely, all of them are. Naming them changes
# no behavior and is not meant to: it is the record of a decision, so that
# turning one off later is an edit to a line that exists rather than an argument
# from silence. This site's whole job is being found, and being read by an
# assistant is now one of the ways a person finds a designer.
#
# Two of these are not crawlers and are worth understanding separately.
# Google-Extended and Applebot-Extended do not fetch anything; they are the
# opt-out tokens governing whether already-crawled pages may be used for model
# training. Allowing them is a permission, not a visit. That is a rights
# decision rather than a technical one, and the way to reverse it is to change
# Allow to Disallow on those two blocks alone -- which does not affect search
# indexing, because they do not control it.
