Lab · three pieces

Design systems for humans and agents

Experiments in React, AI-assisted prototyping, component systems, and interfaces where design decisions survive all the way into code. Self-directed, on synthetic data, and built end to end: each one is a question about how a product team works once coding agents are on it, answered with something that runs.

  1. Agent Review: where design judgment goes when coding agents join the team

    How can someone hand a coding agent more of the work and still understand what it did? Agent Review is a working prototype of the screen they read afterward: results first, boundaries in plain words, the few decisions that are still theirs, and rules they can edit or revoke. Its run is scripted. It was designed from an experiment where Claude Code built one feature twice inside a React component system, with twelve written rules and without.

    Case study Working prototype and public Storybook React TypeScript Storybook Claude Code

  2. Rollcall: a broken deploy the developer can read and roll back

    A multi-service deploy console for the moment something broke, arranged in the order developers ask their five questions: what is live, what failed, what changed, what depends on it, can I put it back. The deploy serving traffic kept apart from the newest attempt, a failed build explained on one card, and a rollback previewed before it runs and undone in one press.

    Working prototype Plain HTML, CSS and JavaScript Synthetic data

  3. Second Look: an AI recommendation the dispatcher can check and overrule

    Human-in-the-loop decision support for freight dispatch: the factors behind a pick shown with their values and their age, a close call that names its tradeoff rather than picking, a legal limit the system enforces before it scores, and a one-click override that asks why afterwards. Built on one hypothesis: a dispatcher spends less time reconstructing a recommendation when the interface shows what needs checking.

    Working prototype Plain HTML, CSS and JavaScript Synthetic data
