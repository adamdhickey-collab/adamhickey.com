Designing motion with Claude Code

A three-step scroll story from the homepage, kept as an exploration of motion built with Claude Code. As you scroll, a blueprint is handed off, a tree grows every branch at once, then it’s pruned and bears fruit.

  • Scroll position sets the playhead of one anime.js timeline, with a little lag so it carries weight
  • Each step holds at its center, so stopping always lands on a finished state
  • With reduced motion it jumps between those held states; without JavaScript the finished drawing stays

What changes when agents can build

01

For most of my career, design ended at the handoff.

I drew the blueprint. Someone else built it. Months later, we found out what survived the translation.

02

Now the building is the fast part.

I build what I design, with coding agents. Working software in days, not months. And an agent grows every branch it’s asked for, plus a few it wasn’t.

03

The judgment didn’t go away. It moved.

Growing is easy. Pruning is the craft. More of the job now is deciding what to cut back, and which calls an agent should never make on its own.
