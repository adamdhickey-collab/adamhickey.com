What makes an interface feel finished?

Finished is when nothing on the screen is left to a default. Taste chose the sizes, colors, motions, states, and gaps, and what makes them finished is that each is written down and checked.

In this article

  1. Finished is when nothing is left to the defaults
  2. Type is a scale, not a set of sizes
  3. Color is a pair, not a swatch
  4. A state is a decision, and every state gets one
  5. Craft is what you can hold the page to

Key idea 1 of 5

Finished is when nothing is left to the defaults

Ask what makes an interface feel finished and most answers are a mood: polished, considered, calm. Those are true and useless, because you can’t check a page for calm.

What you can check is the thing under the mood. An interface feels finished when every value on it was decided, and unfinished exactly where a browser, a framework, or a hurry decided instead.

The default line height. The default blue. The 300-millisecond transition, because that was the number in the example. I think together they’re the difference between software that feels made and software that feels assembled.

Key idea 2 of 5

Type is a scale, not a set of sizes

A finished interface has a small number of type sizes, and every piece of text is one of them. This site has fourteen, from 11px to 80, and a check refuses any size not on the list at four widths.

Leading and tracking follow the size: display type sits tight, reading type sits open, and an essay’s line runs to fifty-two characters, about as long as a line can be before the eye loses the way back.

Spacing works the same way: nine fixed steps from 4px to 48, and every gap is one of them. That’s why two components made a month apart sit together as if they were made in one afternoon.

Nudged looks right today. Decided looks right next to the thing built next year.

Key idea 3 of 5

Color is a pair, not a swatch

A color is never on its own. It’s ink on a ground, and the number that matters is the ratio between them, so a finished palette is small enough to tabulate every pair.

This site’s sage accent is two tokens. The fill that clears a 2px rule fails small type at 3.56:1, so the text step, at 5.82, does that job. Same hue, two jobs, two numbers.

Most palettes miss text on a picture, where there’s no ground color to compute from. That’s how a caption on this site’s own hero once shipped at 3.88:1 against a 4.5 floor.

Finished color is every pair on the page having a number, including the pairs that only exist once the photograph loads.

Key idea 4 of 5

A state is a decision, and every state gets one

Every control has more states than the one in the mockup: hover, focus, pressed, disabled, loading, refused, and whatever a script adds. An unfinished interface designs one and lets the framework paint the rest.

In Dispatch Cockpit, my prototype, the interesting states only exist after a press. When a rule refuses an assignment, the refusal sits above the recommendation in the one caution color, with the hours-of-service limit that caused it.

Motion is how a state arrives, and it’s where unfinished shows fastest. This site has one easing curve and six durations, from 120 milliseconds to 900.

If a reader scrolls back while something is animating in, the honest interface rewinds it. And every animation resolves to its finished state when the motion is absent, for reduced motion, no script, or a search engine.

An interface feels finished when every value on it was decided, and unfinished exactly where something else decided instead.

Key idea 5 of 5

Craft is what you can hold the page to

A list of decisions decays. Someone adds a size, a color, a 300-millisecond transition, and none of it is wrong enough to notice.

So the last thing that makes an interface finished is off the screen: checks that measure the rendered page and refuse the change that breaks a rule.

The curve check surprises people. A rounded surface with a border that stops where the radius begins is one of the most reliable tells of an unfinished page, and a renderer does it by default.

None of this replaces an eye. The eye chose every step on those scales. The checks let the choice survive the next person to touch the page.

In one breath

Finished is when nothing is left to a default: every size, color, state, motion, and gap decided, and checks that hold it after the person who cared has moved on.

If you do one thing: open your product’s stylesheet and count the distinct font sizes, transition durations, and hex colors. The number you get is how many decisions nobody made.
